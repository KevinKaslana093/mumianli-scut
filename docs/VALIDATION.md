- 三校区起止时间、单双周 / 间断周、不同节号的跨校区时钟冲突、CSV 引号与校区往返、停课与学期外补课、UTC+8 ICS、非法日期与节次：7 项 Node 测试。

- 手机浏览器：新建课程、本机持久保存、周次筛选、坏文件不覆盖旧课表、CSV 预览确认、国际校区课程时刻、注册、恢复码提示、发帖、评论、无整页横向溢出。

- TypeScript 编译检查通过；生产构建通过。后续最终发布构建结果以交付说明为准。

## 验证环境和边界

Windows 本机 Chromium，手机尺寸模拟；未使用真实学生教务账号或真实个人课表。所有测试账号、帖子及评论仅位于本地 D1，不复制至生产数据库。

生产构建预览曾遇到 Windows 本机 Wrangler/Miniflare 连接重启，开发预览下 API 和浏览器流程通过；生产托管是否稳定需由发布后在线检查确认，不将本地预览等同于上线验收。

未覆盖学校最新真实 PDF / HTML 布局、所有手机品牌、校园网与微信内置浏览器、邮箱投递（未接入）及大规模并发。

## 敏感信息扫描

通用发布检查脚本会误报 PDF.js 中处理加密 PDF 的 `password` 字段，以及本地测试用的虚构密码。PDF.js worker 与 npm 安装的原文件逐字节校验；原文件不含本站密钥。工作目录内的参考仓库为公开源码，不进入发布源。真实管理密钥只在被忽略的 `.dev.vars`、用户交付的私有管理说明和托管秘密变量中。

## 线上检查

2026-10-22 首次公开发布后，真实 Chromium 浏览器可打开首页；校园墙与账号状态 API 返回 200，数据库没有本地测试帖子；`.env`、`STATUS.md` 返回 404。未发现页面运行错误（主动验证不存在路径时产生的预期 404 除外）。

命令行 HTTP 检查被托管平台 Cloudflare 防护返回 403；浏览器访问及同源 API 请求正常。不能据此承诺所有校园网、地区或微信内置浏览器均可访问；未进行这些网络环境的实测。
